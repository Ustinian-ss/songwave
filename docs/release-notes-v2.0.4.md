# 声浪 SongWave v2.0.4

> 🎨 取色器可见可用 · 📐 左侧功能栏不再拥挤 · 📻 榜单平台可用性透明化

## 🎨 修复：色彩混搭的取色器「看不见」

面板里的取色器 HTML 一直在，但**缺少样式**，`<input type="color">` 被压成一个小色块，基本没法用。

现在：
- 取色器放大到 **46×30**，带边框/圆角/悬停反馈，点开即系统调色板（色板自选任意颜色）
- 右侧实时显示**十六进制色值**（如 `#67dce7`）
- 混搭强度滑块与「混搭（自选两色）」主题档联动，色相沿最短弧插值 → 光子按半径、音柱按柱位渐变

## 📐 修复：左侧功能栏拥挤 / 显示不全

功能栏按钮已增加到 **9 个**（搜索/列表/我喜欢/历史/发现/歌单/歌词/壁纸/设置），原来固定尺寸在窗口不高时会被裁切。

现在：
- 按钮 **38→34px**、间距收紧，并支持**纵向滚动**（滚动条隐藏）
- 按窗口高度**自适应**：`≤700px` 进一步压缩，`≤600px` 再缩一档
- 保证任意窗口高度下 **9 个按钮都完整可见**

## 📻 说明：为什么榜单只有网易云 / QQ / 酷狗

这是**平台接口的现实情况**，不是没做：

| 平台 | 榜单接口状态 |
|---|---|
| 网易云 | ✅ 可用 |
| QQ音乐 | ✅ 可用 |
| 酷狗 | ✅ 可用 |
| 酷我 | ❌ 需页面动态生成的 `csrf` token（直接请求返回 `The request is illegal!`） |
| 咪咕 | ❌ 接口已改版（返回 301 重定向/HTML，需 App 签名） |

现在「发现」页会**明确写出可用与不可用的平台及原因**，不再让人疑惑：

> 榜单接口可用：网易云 / QQ / 酷狗；酷我（接口需页面动态 token）、咪咕（接口已改版（需 App 签名））暂不可用

（酷我/咪咕的**搜索**同样不可用，但搜索失败会自动回退网易云，不影响使用。）
