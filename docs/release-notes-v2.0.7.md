# 声浪 SongWave v2.0.7

本次修两个直接影响"能不能播"的问题：**切酷我被弹回网易**、**歌词出来了但不播放**。

## 1. 酷我：搜索修好、并内置原生取链

- **搜索**：`www.kuwo.cn/api/www/search/*` 现在强制要求 csrf token，无 token 一律返回
  `The request is illegal!`（这就是之前酷我搜索**静默 0 结果**、进而被"自动回退网易云"弹回去的原因）。
  已改走仍然可用的 `search.kuwo.cn/r.s`（`rformat=json` 返回标准 `abslist`），并处理了
  `MUSIC_` 前缀、HTML 实体（`&nbsp;`/`&amp;`）、封面（`web_albumpic_short`）与时长字段。
- **取链**：酷我新增**内置原生取链**（`antiserver.kuwo.cn/anti.s?type=convert_url` 直接返回 mp3）。
  取链顺序是 **扩展音源脚本优先 → 内置兜底**，所以脚本失效也能出声。
- **搜索回退不再改写你的音源选择**：以前回退会顺手把音源切成网易并写进配置，于是"切酷我就弹回网易"；
  现在只提示原因（"酷我 暂无结果，下面显示的是网易云的结果，音源选择未改动"），下次仍按你选的平台重试。

> 实测：酷我搜索「野火」→ 20 条真实结果，选中音源保持"酷我"，点击即可出声。

## 2. 「歌词有了但不播放」的真根因：歌词接口有授权、播放接口没有

实测网易云 **野火 - 戾格（id 1981028372）**：

```
播放地址 https://music.163.com/song/media/outer/url?id=1981028372.mp3
  → 302 https://music.163.com/404   Content-Type: text/html
歌词接口 https://music.163.com/api/song/lyric?id=1981028372  → 正常返回
```

歌词拿得到、音频拿不到，播放器只能**静默失败** —— 看起来就是"歌词都出来了，就是不出声"。

现在取链时会**先探测一次响应头**（只取 header 立即断开，不会把整首歌拉下来；结果缓存 10 分钟）：
判定不是音频就当场报错 **「网易云没有该歌曲的播放版权（返回的不是音频（text/html;charset=utf8））」**，
并立刻走自动换源，而不是让用户对着歌词听空气。

## 3. 试听片段：识别、如实提示、优先找完整版

酷我对官方/VIP 歌曲只返回**约 11 秒试听**（实测 181KB mp3）。现在能精准识别：

- 用 `Range: bytes=0-1` 探测时必须读 **`content-range`**（`bytes 0-1/181521` → 整首 181521 字节）——
  只看 `content-length` 会得到"2 字节"，于是把每首歌都误判成"约 1 秒试听"（这个 bug 本次一并修掉）；
- 自动换源会**跳过只有试听片段的平台，先找完整版**，实在没有才退回试听；
- 界面如实提示「酷我仅提供试听片段（约 11 秒，受版权/会员限制）」，试听播完也**不再报"换源失败"**。

实测对照（同一接口）：

| 歌曲 | 声明时长 | 实际取到 | 判定 |
| --- | --- | --- | --- |
| 晴天 - 周杰伦（官方版） | 269s | 约 11s | 试听片段 |
| 晴天+告白气球（用户上传） | 506s | 约 506s | 完整版 |

## 4. 顺手修掉的体验问题

- 搜索结果行**音源标注错误**：此前只要不是扩展音源就一律标"网易"，酷我/QQ/酷狗的结果全被标成"网易"，现在按真实平台标注；
- **换源并发去重**：点播放和 audio 的 error 事件几乎同时触发，此前会跑两轮换源，第二轮在 12 秒后才回来把
  "已换源播放"的成功提示覆盖成"换源失败"；现在同一首只跑一次；
- **进度记忆不再续播到结尾**：试听片段只有 11 秒，续播到 11s 会"一开就结束"（看着像坏了），现在接近结尾时不续播；
- **日志增强**：错误信息带 `err.cause`。这次就是靠它定位到你导入音源的真实失败原因 ——
  `fetch failed ← getaddrinfo ENOTFOUND flower.tempmusics.tk`（flower 音源的作者后端域名已失效，
  与播放器无关；现在有内置取链兜底，脚本挂了也能播）。
