# 声浪 SongWave v2.0.5

> 🌀 修复「可视化地形不动了」

## 🐞 根因

地形**看起来冻住**，不是渲染坏了，而是引擎被判定为「有音频输入但在静音」：

1. 播放过歌曲后，可视化会用**系统音频回环**抓声音 → 引擎标记 `audioOn = true`
2. 音乐暂停/停止后，回环仍在但**没有任何声音** → 分析器数据全是 0
3. 引擎只在 `audioOn === false` 时走**演示动画**（`demoEnergy`）→ 此时既没有真实音频、也不走演示动画 → **画面像死了一样**
4. 早期版本里还有个"看门狗"会在静音时切到**直连模式**，同样把 `audioOn` 置为 true，效果一样

（实测确认：渲染循环一直在跑、`state.time` 持续增长，所以不是主循环停了，而是**画的东西没有能量**。）

## ✅ 修复

在引擎里加入**无信号自动回演示动画**：

- 新增 `state.silentFor`：连续无信号时长；静音超过 **2.5 秒**即视为"没有声音在放"
- 统一判断 `useDemo()`：**没有音频源 或 连续静音** → 走演示动画；有声音立刻切回真实频谱
- **频谱柱不再因为低电平整块不画**（原来 `audioLevel < 0.02` 直接 return，导致柱子一根都没有）
- 光子能量、闪烁、频谱取值全部走同一套判断，避免出现"有的动有的不动"

结果：**任何时候画面都在动** —— 放歌时跟着音乐跳，没放歌时自动演示。

## 🧪 验证证据（对打包版实测）

```

t+4s 截图哈希: db79998c0bca5
→ ✅ 画面在动（哈希持续变化）
```

新增回归测试 `test:viz`（校验引擎具备 demo 回退逻辑），**15 套测试 / 373 条断言全绿**。

## 💡 如果你觉得"地形还是不明显"

检查面板 →「背景 · Wallpaper Engine」的**背景模式**：

- **仅可视化** = 只看音域地形（推荐想看清地形时用）
- **叠加** = 壁纸 + 地形混合，地形透明度 85%（我实测你当前就是这个模式，壁纸会"抢戏"）
- **仅壁纸** = 完全看不到地形（这是预期行为）

用「叠加」时可以把「可视化不透明度」拉满，或直接切到「仅可视化」。
