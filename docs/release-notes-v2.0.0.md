# 声浪 SongWave v2.0.0

> 第二个大版本：**发现音乐** 与 **更顺手的日常使用** —— 排行榜/推荐、独立桌面歌词浮窗、下载增强、多歌单、歌词罗马音与简繁、系统托盘

本次更新集中在「用起来更完整」：从「能搜能放」升级到「像一款真正的播放器那样日常可用」。

## 📦 安装

1. 下载下方 `SongWave-Setup-2.0.0.exe`
2. 双击安装（未做代码签名，SmartScreen 提示 → **更多信息 → 仍要运行**）
3. 打开即用；其它平台（QQ/酷狗/酷我/咪咕）取链请在「⚙ 面板 → 音源管理」导入音源脚本

## ✨ 本版新增

### 📻 发现页（排行榜 / 推荐歌单）
- 左侧功能栏新增 **📻 发现**：网易云 / QQ / 酷狗 三平台排行榜一键切换
- **✨ 推荐歌单**：网易云个性化推荐，点击即载入整张歌单
- 榜单/歌单支持「播放全部」或单曲加入播放列表

### 🎵 我的歌单（多歌单管理）
- 左侧 **🎵 歌单**：新建 / 重命名 / 删除 / 一键播放
- 歌单数据本地持久化，与「我喜欢」「播放历史」并存

### 🪟 独立桌面歌词浮窗
- 独立透明置顶小窗，**可自由拖动**、随播放实时同步（当前句 + 下一句）
- **锁定穿透**：锁定后鼠标点击穿透，不挡操作
- 小窗内置工具条：字号 −/+、锁定、关闭；样式与主界面「桌面歌词」设置联动
- 位置自动记忆，下次打开原位显示

### 📥 下载增强
- **命名模板**：`{name} {artist} {album} {index} {quality} {date}`，非法字符自动清理、空字段不留多余分隔符
- **并发下载**：1~6 并发（队列 + 进度上报 + 一键取消）
- **按歌单分组**：自动落到子目录
- **保存 .lrc 歌词文件**
- **ID3v2.3 标签嵌入**：封面（APIC）+ 歌词（USLT）+ 标题/歌手/专辑，中文以 UTF-16 写入，**自研实现零依赖**，重复写入不会叠加旧标签
- 面板一键「下载播放列表全部」

### 🈶 歌词选项
- **翻译**（网易云 tlyric）
- **罗马音**（romalrc，日文歌友好）
- **简繁转换**：内置 1177 字映射 + 38 组词优先匹配，正确处理「一简对多繁」——
  头发→頭髮、发展→發展、干净→乾淨、面条→麵條、台湾→臺灣

### 🖥 系统托盘
- 托盘图标 + 右键菜单：显示/隐藏主窗口、播放/暂停、上一首、下一首、桌面歌词开关、退出
- 悬停提示显示当前歌曲
- 可选「关闭窗口时最小化到托盘」，真正退出走托盘菜单

## 🧪 质量

**12 套测试、338 条断言，全部离线可跑**（无需网络与 Electron）：

```bash
npm run test:all
```

新增覆盖：命名模板与 ID3 标签往返解析、并发队列（峰值并发、分组落盘、歌词文件、失败收集）、简繁歧义词、三平台榜单与推荐解析、以及渲染层的发现页/歌单/托盘/浮窗/歌词选项/批量下载交互。
