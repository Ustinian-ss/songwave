# 声浪 SongWave v1.0.0

> 🎵 音画一体的桌面音乐播放器 —— 多平台音源 · Wallpaper Engine 壁纸背景 · 音域地形可视化 · 10 段 EQ · 桌面歌词

首个正式版本。基于 **Electron + Web Audio**，把「能放歌」和「好看」放进同一个窗口。

## 📦 安装

1. 下载下方的 `SongWave-Setup-1.0.0.exe`
2. 双击安装（未做代码签名，若出现 SmartScreen 提示 → **更多信息 → 仍要运行**）
3. 打开后左侧搜索即用

> 系统要求：Windows 10/11 x64。无需 Node 环境。

## ✨ 本次包含

### 播放与音源
- **五平台音源切换**：网易云 / QQ音乐 / 酷狗 / 酷我 / 咪咕（搜索框下方一键切换并记忆）
- **播放失败自动换源**：取链失败时按「歌名 + 歌手 + 时长」打分匹配，跨平台找同一首歌继续播放，结果写回播放列表；失败时逐平台显示原因
- **扩展音源脚本**：粘贴链接 / 选文件 / 文件夹批量 / 从其它播放器一键导入（含压缩脚本自动解压），支持能力探测、启用停用、重新下载更新、多源并存
- **下载**：流式下载（进度 / 取消 / 跟随重定向 / 重名自动编号 / 目录可设）
- **曲库**：我喜欢、播放历史、搜索历史 + 热门搜索、**导入外部歌单**（网易/QQ 分享链接、文本歌单、本地文件）

### 画面与歌词
- **Wallpaper Engine 壁纸背景**：自动扫描 Steam 壁纸库（创意工坊 + 官方默认工程），视频壁纸直接播放、场景壁纸动图预览；遮罩 / 模糊 / 亮度对比度饱和 / 填充 / 翻转 / 视频速度 / 轮播
- **三种背景模式**：仅可视化 / 仅壁纸 / 叠加；**壁纸模式**（桌面层窗口，置底 + 点击穿透，`Ctrl+Alt+W` 退出）与**沉浸模式**
- **SongLife 可视化引擎**：48 柱频谱地形、光子、光环，WebGL 优先 + Canvas 回退，13 套主题
- **音柱材质 4 种**：玻璃 / **亚克力（磨砂）** / 实心 / 发光，可调模糊 / 透明度 / 高光 / 圆角
- **色彩混搭**：色板自选两色按位置渐变（独立主题档，与音柱材质互不干扰）
- **歌词**：LRC 解析 + 翻译、同步高亮、点击跳转、偏移调节；**播放详情页**（点封面进入，居中大字歌词）；**桌面歌词**（上/下/左/右 · 居中或左右对齐 · 一行或两行 · 字号字重颜色字体描边 · 呼吸/逐字扫过/律动缩放/霓虹发光 动效）

### 声音与播放器
- **10 段 EQ**（31Hz–16kHz）+ **混响**，预设：流行 / 摇滚 / 古典 / 人声增强 / 低音增强 / 电子
- **播放模式**（顺序 / 列表循环 / 单曲循环 / 随机）、**进度记忆**、**倍速**（保持音调）、**定时停止**
- 拖拽排序、序号、来源徽标、面板分组折叠、全套键盘快捷键
