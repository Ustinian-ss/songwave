## 二、新增「一键导入推荐音源」

音源管理面板 → **一键导入推荐音源**，一次装入 4 个（全豆要 / 幻音 / 长青 / 六音）：

- **镜像优先、原始地址回退**：先用 `ghproxy.net` 镜像（国内网络更稳），失败自动回退 `raw.githubusercontent.com`；
- 与"粘贴链接导入"完全等价（脚本不随应用分发，都是点击时才从公开地址下载）；
- 导入后自动后台加载，面板里能看到每个音源的 ok/失败。

## 三、顺手修掉一个缓存策略问题

v2.0.9 的缓存"命中即用"会挡住好音源：如果缓存里存的是 **11 秒试听片段**，它会一直被返回，
即使你已经装了能取完整版的音源。现在改成：

- 缓存里是**完整版** → 直接播（快）；
- 缓存里只是**试听片段** → 只当兜底，**继续找完整版**（音源脚本 → 内置原生），全部失败才退回它，并如实提示。

## 四、推荐的完整用法

1. 装 `SongWave-Setup-2.1.0.exe`；
2. 音源管理 → **一键导入推荐音源**（看到 4 个 ✅）；
3. 想再稳一点：同面板 → **导入已解析地址**（把其它播放器已解析好的地址也拿过来当兜底）；
4. 以后随时点 **音源体检** 复测哪个音源还有效（社区音源的后端会变，这按钮就是用来发现"又挂了一个"的）。
