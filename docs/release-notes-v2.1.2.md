# 声浪 SongWave v2.1.2

把音域地形里那个"**播放时从中心扩散的圆圈**"从平面正圆改成了 **3D 透视圆环**。

## 之前是什么样

那个扩散圈画在 2D 叠加层上，用的是 `ctx.arc(x, y, r)` —— 屏幕坐标系里的**正圆**，
和倾斜的地形平面没有任何关系，所以看起来是"贴在屏幕上的一层平面特效"。

## 现在是怎么做的

圆环改用与地形柱子**同一套网格归一化坐标**（`nx/nz ∈ [-1,1]`），再逐段投影到地形斜面上：

```
persp = 1 / (1 + (nz + 1) * tilt)          // 与 updatePhotons 完全一致
sx    = W/2 + nx * (W*0.46) * persp
gy    = stageH*0.71 - (nz + 1) * 0.5 * stageH * 0.5
```

每一小段按深度单独上色与定粗细：**近处粗、亮、饱和度高；远处细、暗、偏冷**（84 段/环）。
于是圆环真正"躺"在地形平面上，会随着「俯视视角」参数一起改变透视，从地形中心向外扩散时
前缘比后缘更快更亮 —— 和柱子的透视保持一致。

- 节拍触发的光环：从地形中心（`nx=0, nz=0`）向外扩散；
- 点击画面的光环：新增 `screenToGrid()` 反投影，按点击位置换算成地形坐标后再扩散
  （所以点远处会比点近处小，符合透视）。

![3D 地面光环](screens/v2.1.2-3d-ring.png)

## 验证

用 CDP 在地形上按不同位置连续点击触发多个光环，截图确认：圆环呈**明显椭圆**，
近端（画面下方）粗亮、远端（上方）细暗，且与地形的透视网格对齐。
