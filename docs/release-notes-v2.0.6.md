# 声浪 SongWave v2.0.6

本次更新专注一件事：**把「音域地形垂到屏幕最底、被播放条压住」从根上修掉**，并顺手把节奏判定调准。

## 1. 修复：地形不再垂到屏幕最底（WebGL 路径 y 轴镜像）

排查结论（有数据）：

- 引擎的 WebGL 路径走「离屏 FBO → 全屏 quad」两趟渲染，顶点着色器里 `clip.y = -clip.y` 与 quad 的 UV 翻转**叠加成了二次翻转**，净效果是 **上下镜像**；
- 于是本该「立在地面上、向上生长」的柱子一直是**倒挂**渲染的，能量一上来就往下扎到播放条；
- 2D 保底路径（`screenY = engineY`）反而是**对的** —— 也就是说两条渲染路径此前画面是反的。

本次改动：

- 新增参数 `flipY`（默认 `1` = 正立）：着色器改成 `clip.y = mix(-clip.y, clip.y, u_flipY)`，WebGL 与 2D 保底路径**朝向终于一致**；
- 「面板 → 音域地形 → 地形朝向」可切回 `倒挂`（旧观感），会记住选择；
- 正立后柱高是**向上**消耗的，地形最低点被固定在地面线以下不动，**能量再大也不会垂到播放条**。

量化验证（1280×720 窗口，播放条上沿 y=654，均为截图逐行像素实测）：

| 地形朝向 | 可视区最低内容行 | 说明 |
| --- | --- | --- |
| 倒挂（旧） | y = 601 | 只差 51px 就顶到播放条，副歌一上来即被压住 |
| **正立（新默认）** | **y = 417** | 距播放条 **237px**，且与能量无关 |

## 2. 新增：底部留白自动跟随播放条

- 启动与窗口缩放时按播放条**实际高度**设置引擎 `bottomPad`（默认 `66 + 24 = 90px`），频谱柱基线落在播放条上方，不再贴屏幕底；
- 「音域地形 → 底部留白」可手动调（0~240px，会记住）；**双击滑块恢复自动跟随**，标签会显示 `90px 自动` / `120px（手动）`。

## 3. 节奏判定修正

- 静音判定窗口 2.5s → **6s**，并新增峰值保持（`peakLevel`）：歌曲安静段落不会再误判成"没声音"而切回演示动画，也就是不会出现「放歌时节奏跳动不对」；
- 新增 `silenceThreshold` 参数声明（此前只在判定里以默认值兜底，未显式声明）。

## 4. 工程与调试

- 引擎新增 `SongLife.getGeometry()` 探针（真实 `W/H`、后端、光子 y 范围、点尺寸、画布矩形），排查画布/坐标问题不用再靠猜；
- `scripts/` 新增 4 个**零依赖**验证工具，本次修复就是靠它们量化的：
  - `scripts/shot.js` CDP 截图 + 关键几何回读；
  - `scripts/png-rows.js` 纯 JS PNG 解码，逐行亮度 / 亮像素数 / 亮度质心（判断"谁画到了屏幕底"）；
  - `scripts/png-crop.js` PNG 裁剪放大（含垂直翻转预览）；
  - `scripts/calib-shot.js` 改参数前后对照截图（可指定任意参数名）。

## 5. 回归测试

`npm run test:all` —— **15 套 / 373 条断言，全部通过**（含新增的可视化降级与朝向断言）。
