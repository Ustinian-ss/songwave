# 声浪 SongWave v2.0.3

> 🖼 推荐歌单改为**封面网格卡片**（对齐 LX 的展示方式）；并修复「发现页整体失效」

## 🐞 修复：发现页（排行榜 / 推荐歌单）此前完全不可用

`src/charts.js` 导出的是**工厂函数**，而主进程把它当实例调用：

```js
const charts = require('../src/charts');            // ❌ 拿到的是工厂
charts.recommend(...)                               // → charts.recommend is not a function
```

于是点击「✨ 推荐歌单」只会显示「推荐获取失败」，排行榜同理。

修复：改为 `require('../src/charts').createCharts()` 取得实例。
并新增 **`test:chartsapi`** 防呆测试（校验模块导出形态、实例方法、主进程用法、渲染层调用的 action 主进程都支持）。

## 🖼 推荐歌单改为封面网格（对齐 LX）

- **封面网格卡片**：自适应多列（`auto-fill, minmax(104px,1fr)`），1:1 封面、圆角、悬停浮起
- **播放量角标**：右上角 `▶ 6125.4万`（自动按 万/亿 格式化）
- **悬停播放按钮**：卡片右下角出现 ▶，点击直达播放
- **歌单详情头**：点开歌单后显示「封面 + 歌单名 + 歌曲数 + ▶ 播放全部」，不再是干巴巴的一行文字
- 一屏加载 **24 个**推荐歌单
