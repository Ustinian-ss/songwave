# 声浪 SongWave v2.0.2

> 🔧 修复「**怎么切歌都还是那一首**」——根因是部分平台搜索接口失效，导致搜不到新歌

## 🐞 问题根因

现象：打开后**每次都放同一首歌，点别的歌也没用**。

排查过程（用远程调试连上真实应用实测）：

```
playlist 长度: 2              ← 应用恢复了上次的播放列表（只有 2 首旧歌）
搜索结果条数: 0
状态栏 = 搜索失败：返回不是 JSON
```

四个平台音源逐一实测结果（2026-09 现状）：

| 平台 | 结果 |
|---|---|
| 网易云 | ✅ 正常 |
| QQ | ✅ 正常（约 3 秒） |
| 酷狗 | ❌ `mobilecdn.kugou.com` 域名已不可达 |
| 酷我 | ❌ 接口返回 `The request is illegal!`（需 JS 生成的 token） |
| 咪咕 | ❌ 接口改版，返回 HTML（"返回不是 JSON"） |

应用会**记住你上次选的音源**，于是你选了某个已失效的平台后：搜索永远 0 结果 → 加不进新歌 → 只能点到播放列表里那两首旧的 → **看起来就是"怎么切都是那一首"**。

## ✅ 修复

### 1. 搜索失败自动回退（核心）
所选平台**搜索报错或返回 0 条**时，自动改用内置网易云重搜，并在状态栏说明原因：

> 该音源接口不可用（返回不是 JSON），已自动改用网易云

同时把音源选择框**自动切到网易云**，避免每次搜索都先失败一次。

### 2. 酷狗换可用域名
`mobilecdn.kugou.com` → 改为多域名轮询：**`mobiles.kugou.com` → `msearchcdn.kugou.com` → `mobilecdn.kugou.com`**（实测第一个可用，搜索恢复正常）。

### 3. 平台失败不影响其它功能
平台搜索异常不再抛到界面阻断流程；失败的平台会被记为失败并自动绕过。

## 💡 使用建议

- **默认用网易云**（内置、免登录、最稳）；QQ 也可用
- 酷狗/酷我/咪咕接口当前不稳定，**建议不要选**；万一选了也能搜到歌（自动回退网易云）
- 其它平台要播放，需在「音源管理」里导入**能用的**音源脚本（如 `flower` / `野花`）
